# 价带汇总服务

成交价以**分**（整数）存储；价带规则按版本**独立发布**；分桶为半开区间 `[lo, hi)`，
价格等于边界的交易只进一个桶。仅用 Node.js 内置模块，无第三方依赖。

## 运行

```bash
node server.js          # 读取 PORT，默认 3000，绑定 127.0.0.1
PORT=8080 node server.js
```

打开 `http://127.0.0.1:3000/`，页面上可依次操作（数据走真实 API 流程）：

1. **生成旧价带汇总** — 按 v1 旧边界 `[1000,2000,5000]` 生成并留档；
2. **发布新边界** — 发布 v2（默认 `1500,3000`）并自动按新规则重算新报表，旧报表保持旧边界；
3. **查看边界交易** — 列出价格恰好等于边界的交易及其唯一归属桶。

页面可切换计价口径（优惠前 gross / 优惠后 net）与计算方式（缓存分粒度中间结果 cached /
逐单重算 raw）。业务结果区带 `data-evidence-result` 属性，标记最近一次操作，便于核对前后内容。

## 测试

```bash
node --test
```

覆盖：半开区间边界归属、总数守恒、口径切换不错误复用缓存、分粒度中间结果跨版本复用、
raw 与 cached 一致性、留档报表保留旧边界、数据变更缓存失效，以及非法边界 / 口径 / 版本 /
交易 / JSON 请求体等异常路径。

## 结构

- `lib/bands.js` — 领域核心：价带注册表、分桶、分粒度直方图缓存、汇总与留档报表；
- `lib/sample-data.js` — 合成样例（12 笔，含压边界与含优惠的交易）；
- `server.js` — HTTP 服务与路由（`GET /`、`/api/state`、`POST /api/reports`、
  `GET /api/reports/:id`、`POST /api/bands/publish`、`GET /api/boundary-transactions`、`POST /api/reset`）；
- `public/index.html` — 操作页面；
- `test/` — `node --test` 用例。

## 缓存键设计

`数据版本 : 计价口径 : 价带版本`。口径从优惠前切到优惠后（或反之）键必然变化，
不会错误复用旧汇总；价带变更只使汇总缓存换键，分粒度直方图（中间结果）仍可复用；
数据变更则整体失效。
